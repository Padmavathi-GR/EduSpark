# EduSpark Design System

## 1. Colour Palette

- Primary Colour: Green (#477A52)
- Background Colour: Cream (#FFF9E9)
- Secondary Colour: Dark Green (#355B3D)
- Card Colour: White (#FFFFFF)
- Main Text Colour: Gray (#1F2937)
- Secondary Text Colour: Gray (#374151)

## 2. Typography

- Primary Font: Geist
- Monospace Font: Geist Mono
- Headings: Bold
- Body Text: Regular
- Main Headings: 30px
- Section Headings: 20px
- Body Text: 16px

## 3. UI Components

- Navigation bar
- Dashboard cards
- Subject cards
- Quiz option buttons
- Submit Quiz button
- Result and recommendation cards
- Progress section

## 4. Button Styles

- Primary Button: Green (#477A52) with white text
- Hover Button: Dark Green (#355B3D)
- Rounded corners
- Comfortable padding

## 5. Design Style

- Simple and clean layout
- Rounded cards
- Soft shadows
- Green buttons with white text
- Cream background
- Consistent spacing
- Easy navigation for students
